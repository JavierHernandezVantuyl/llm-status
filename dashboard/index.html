🤖 LLM Chat Usage Dashboard

Track your conversation limits across all LLMs

Note: This tracks CHAT usage (claude.ai, chatgpt.com conversations), NOT API usage. For Claude, this is the same quota shown in Claude Code's /usage command.

📋 How to Use

  1. Make sure you're logged into claude.ai in this browser
  2. Click "Refresh Usage" on the Claude card
  3. The dashboard will fetch your current chat usage automatically
  4. Bookmark this page for easy access

Privacy: All data stays in your browser. Nothing is sent to external servers.
